# 深渊回响：终焉之镜 · 开发文档

> Minecraft 1.20.1 / Forge 47.3.0 / Java 17 / Mod ID `mirror_abyss`
> 本文档面向模组开发者，覆盖注册体系、内容管线、世界生成、网络与结局，以及常见开发流程。

---

## 1. 总览

| 项 | 值 |
| --- | --- |
| 包名 | `com.example.mirror_abyss` |
| 注册方式 | `DeferredRegister`（全部注册表）+ 数据驱动 JSON |
| 命名 | 全部 snake_case；英文注册名，注释英文 |
| 资源命名空间 | `assets/mirror_abyss` 与 `data/mirror_abyss` |

**核心循环**：主世界挖 `abyss_ore` 得 `mirror_shard` → 搭建 `mirror_portal_frame` 4×5 框架并激活 → 进入镜渊（永久暮色）→ 收集 `void_eye`，在 `watcher_altar` 献祭传送到虚空圣殿 → 击败三阶段 Boss `mirror_eater` → 获得 `final_mirror_item`，右键 `final_mirror` 选择结局。

## 2. 注册体系

所有注册集中在 `MirrorAbyss.java` 构造函数中挂载到 mod 总线：

```java
ModBlocks.BLOCKS.register(modBus);            // 方块
ModItems.ITEMS.register(modBus);              // 物品
ModEntities.ENTITY_TYPES.register(modBus);    // 实体
ModBlockEntities.BLOCK_ENTITY_TYPES.register(modBus);
ModMenuTypes.MENU_TYPES.register(modBus);     // 结局 GUI 菜单
ModEffects.MOB_EFFECTS.register(modBus);      // 虚空侵蚀
ModCreativeTabs.CREATIVE_TABS.register(modBus);
ModSounds.SOUND_EVENTS.register(modBus);           // 音效事件
ModDimensions.DIMENSION_TYPES.register(modBus);    // 维度类型（代码注册）
ModBiomes.BIOMES.register(modBus);                 // 群系
// 结构：纯数据驱动（minecraft:jigsaw + template_pool），无需 Java 注册
// 事件接线：modBus.addListener(ModEntities::registerAttributes / registerSpawnPlacements)
```

三类"代码 + 数据"混合注册：

| 内容 | 代码注册 | 数据注册 |
| --- | --- | --- |
| 维度 | `DimensionType` 在代码中声明（`fixed_time=12000` 永久暮色） | `data/mirror_abyss/dimension/` + `dimension_type/` |
| 生成器 | `MirrorAbyssChunkGenerator`/`MirrorAbyssBiomeSource` codec 注册进 `BuiltinRegistries` | `worldgen/noise_settings`、`worldgen/biome/*.json` |
| 结构 | 无（`minecraft:jigsaw` 原生类型） | `worldgen/structure/*.json` + `template_pool/` + `structures/*.nbt` |
| 天空特效 | `MirrorAbyssEffects` 客户端注册进 `dimension_effects` | `dimension_type` JSON 的 `effects` 字段指向 |

## 3. 方块与方块实体

10 个方块全部有 blockstate / model / loot_table / lang。行为方块独立成类：

- `MirrorShardBlock`：`REFLECTING` 状态 + `reflectBeam()` 折射逻辑挂点
- `VoidStabilizerBlock` + `VoidStabilizerBE`：`SUPPRESS_RADIUS=8`，蓄能 20s 后 `isProtected()` 生效；Boss 阶段 3 检测它打断蓄力
- `WatcherAltarBlock`：手持 `void_eye` 右键 → 消耗并 `teleportToVoidSanctum`，`ACTIVATED` 高亮 3s
- `FinalMirrorBlock` + `FinalMirrorBE`：`use()` 打开 `FinalMirrorMenu`，结局写入 BE 的 `ending` NBT
- `VoidFloorBlock`：`stepOn` 每 tick 2 点魔法伤害，稳定器范围内免疫
- `ReflectiveLampBlock`：亮度 12，`scanBeam()` 沿 +X 扫描 24 格，命中祭坛触发 `light_refraction` 成就
- `MirrorPortalFrameBlock`：4×5 框架校验 + `ACTIVATED`

方块实体须注意：`BlockEntityType.Builder.of(...).build(null)` 的 null 参数是 1.20.1 要求（工厂参数已弃用）。

## 4. 实体

| 实体 | 类别 | 要点 |
| --- | --- | --- |
| `mirage_walker` | Monster | `MirrorShardAwareTargetGoal`：玩家持碎片且静止则不攻击；弹射物减伤 50% |
| `void_devourer` | Monster (NoGravity) | `RangedAttackGoal` 发射 `void_bolt`；近身 aura 施加 `void_erosion` |
| `crack_spider` | Monster | `onClimbable()` 爬墙；每 5s 在脚下生成 `void_floor` |
| `mirror_eater` | Boss | 见 §4.1 |
| `void_bolt` | AbstractHurtingProjectile | 命中施加 5s `void_erosion` |

属性/生成注册：`EntityAttributeCreationEvent`（`ModEntities.registerAttributes`）。**注意**：`MirrorAbyss` 构造函数目前未把 `registerAttributes` 挂到 `EntityAttributeCreationEvent`——正式实现需在 mod 总线添加：

```java
modBus.addListener(ModEntities::registerAttributes);
```

### 4.1 噬镜者三阶段

```
血量 >66%  P1  近战 + 召唤 2 只镜影行者 + 反弹弹射物（0.5 倍回敬）
血量 33-66% P2 传送玩家 + 6 格范围伤害 + 镜片飞散（贴图占位）
血量 <33%  P3  蓄力 100 tick「虚空湮灭」：
               - 场地内有满充能 void_stabilizer → 打断（每 20 tick 检测）
               - 否则蓄满 → 24 格内 30 点 AoE
```

Boss 血条：`ServerBossEvent`（紫条、全屏变暗），进入/离开视角自动增删玩家。客户端 `CHARGING_ACCESSOR` 驱动蓄力脉冲动画。

## 5. 客户端（模型 / 渲染 / GUI）

- `client/ClientSetup.java`：`@Mod.EventBusSubscriber(Dist.CLIENT)`，注册 5 个 `ModelLayerLocation`、5 个渲染器、`FinalMirrorScreen`
- 半透明：`MirageWalkerRenderer`/`VoidDevourerRenderer` 覆写 `getRenderType()` 返回 `RenderType.entityTranslucent`
- `VoidBoltRenderer`：EntityRenderer + 0.4 缩放立方体，85% 透明度
- `FinalMirrorScreen`：无槽位菜单，两个按钮 → `FinalMirrorChoicePacket` → 服务端

模型均为占位 cube 几何（16×16 贴图，整图映射）。升级路径：换成 GeoModel（`geckolib`）或逐面 UV。

## 6. 世界生成

### 6.1 维度链

```
data/mirror_abyss/dimension/mirror_abyss.json
  └─ type: mirror_abyss:mirror_abyss（dimension_type JSON：fixed_time=12000，effects=自定义）
  └─ generator:
       ├─ type: mirror_abyss:mirror_abyss（MirrorAbyssChunkGenerator codec）
       ├─ settings: mirror_abyss:mirror_abyss_noise_settings（surface_rule 切裂隙岩/镜面/虚空地面）
       └─ biome_source: mirror_abyss:mirror_abyss_biome_source（哈希选 3 群系）
```

### 6.2 群系与地物

- `mirror_plains` / `cracked_badlands` / `void_ruins`：均为无降水、紫灰天空；spawners 配好三种镜渊生物
- 地物：`ore_abyss_ore`（trapezoid -60~80，每区块 12 次）、`mirror_shard_cluster`（random_patch 24 tries）
- 主世界深层注入：`forge/biome_modifier/add_abyss_ore_overworld.json`（`#minecraft:is_overworld`，-64~-20，每区块 4 次）

### 6.3 结构（Jigsaw 数据驱动）

三个结构已升级为**纯数据驱动 Jigsaw**：`.nbt` 由 `tools/generate_structures.py`（无依赖的 NBT 编码器，gzip + Structure-Block 格式，DataVersion 3465）生成，Java 侧程序化结构代码（`MirrorRuinsStructure`/`ModStructures`）已删除。

| 结构 NBT | 尺寸 | 内容 |
| --- | --- | --- |
| `watchers_ruin` | 16×8×16 | 砖墙遗迹、中央 `watcher_altar`、镜面嵌饰、北门 |
| `mirror_hallway` | 16×6×16 | 镜面走廊、墙上 `reflective_lamp`、端墙砖门框 |
| `void_sanctum` | 16×5×16 | 竞技场、中心 6×6 `void_floor`、四角 `void_stabilizer`、**实体条目内嵌 `mirror_eater`**（生成时自动召唤 Boss） |

接线关系：

```text
worldgen/structure/<名>.json  (type=minecraft:jigsaw)
  └─ start_pool → worldgen/template_pool/<名>/start_pool.json
       └─ element.location = mirror_abyss:<名> → structures/<名>.nbt
worldgen/structure_set/<名>.json (random_spread)
tags/worldgen/biome/has_structure/<名>.json
```

重建命令：`python3 tools/generate_structures.py`（脚本输出与 nbtlib 交叉验证通过：palette/state 索引/尺寸/Boss 实体 UUID 均正确）。

## 7. 网络与结局

```java
ModNetwork.CHANNEL  // SimpleChannel "mirror_abyss:main"，PROTOCOL_VERSION="1"
  id 0 → FinalMirrorChoicePacket(int ending)
```

服务端处理链：`FinalMirrorChoicePacket.handle` → 就近写入 `FinalMirrorBE.ending` → `EndingEffects.apply(player, ending)`：

| ending | 结局 | 服务端效果（骨架） |
| --- | --- | --- |
| 1 | 封印虚空（和平） | 全服广播 + 饱和/再生 buff；扩展点：镜渊全局裂隙抑制 |
| 2 | 融合现实（混沌） | 全服广播 + 玩家周围生成 16 块 `void_floor`；扩展点：定时"虚空蔓延"事件 |

两者都触发 `final_decision` 成就触发器（`CriteriaTriggers.register` 已注册）。

## 9. 贴图管线

所有占位贴图程序化生成（`tools/generate_textures.py`，种子 `20241016` 可复现）：

```bash
python3 tools/generate_textures.py
# → textures/block（24 张）textures/item（7 张）textures/entity（5 张）textures/gui（1 张）
```

升级 32×32：改 `new_img(base, size=32)` 与各函数循环步长即可，模型与分辨率无关。

## 10. 常见问题

- **结构不生成**：检查 `structure_set` 的 salt/spacing 是否合理、群系标签是否存在；Jigsaw 结构用 `project_start_to_heightmap: WORLD_SURFACE_WG` 贴地，若维度地表被覆盖需调 `terrain_adaptation`。
- **实体看不见**：确认 `EntityRenderersEvent.RegisterRenderers` 已注册、纹理路径与 `getTextureLocation` 一致。
- **Boss 不掉落**：实体 loot table 路径必须是 `data/mirror_abyss/loot_tables/entities/<注册名>.json`（`EntityType.getLootTable()` 自动推导 `entities/` 前缀），不要同时用 `spawnAtLocation` 手写掉落（会双份）。
- **维度类型报错**：`MirrorAbyssChunkGenerator`/`MirrorAbyssBiomeSource` 的 codec 必须已 `Registry.register` 进 `BuiltinRegistries`，否则 datapack 加载报"unknown generator type"。
- **天空没生效**：`dimension_type/mirror_abyss.json` 的 `effects` 必须等于 `mirror_abyss:mirror_abyss`，且 `MirrorAbyssEffects.register()` 在客户端 `FMLClientSetupEvent` 已执行。
- **音效无声**：`sounds.json` 的条目用 `"type": "event"` 回退到原版事件，不需要 ogg；正式版替换为真实音频文件时删除 `type` 字段即可。
- **Java 版本**：必须 JDK 17 编译/运行（系统默认 JDK 11 会报 class version 错误）。
